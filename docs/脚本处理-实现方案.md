# 脚本处理 实现方案

状态：已拍板方向，待实现。
拍板：不做插件内调度（定时交给操作系统）；脚本产物契约 = vault 内 CSV 文件；显示链路复用现有 CSV 自定义数据源。

## 1. 功能定位

用户用独立编写的 Python 脚本做复杂数据计算，脚本把结果写成 CSV 文件放进 vault，插件把这些 CSV 自动注册为 CSV 自定义数据源，从而以现有卡片体系（独立卡 / 叠加卡 / 计算卡）显示在 Canvas 上。

- 脚本的运行独立于插件：用户可以用 cron / launchd / 任务计划自己跑，也可以在插件里手动点「立即运行」。插件不提供定时调度。
- 插件与脚本之间唯一契约是 CSV 文件格式。插件不 import 用户代码、不发明 IPC。
- 脚本必须遵守插件的使用边界（不高频抓取、不批量下载保存）。技术上唯一的硬约束是「立即运行」由用户手动触发；规则层面通过「AI 辅助」提示词、脚本模板和免责声明约束。

## 2. CSV 产物契约

脚本输出文件必须满足（即现有 `parseCsvKline` 已支持的两种模式）：

- 位置：脚本文件夹（设置项，vault 内）下的 `output/` 子目录，建议与脚本同名：`脚本/foo.py` → `脚本/output/foo.csv`。
- 编码 UTF-8，首行表头。
- 单序列 OHLCV 模式：表头含 `date,open,high,low,close`（vol/amount 可选）。
- 宽表模式（推荐，一个脚本可产出多序列）：首列为日期列（`date` / `trade_date` / 时间戳均可，`normalizeJsonDate` 已支持 ISO / YYYYMMDD / epoch），其余每个数值列即一条序列，列名即代码。
- 数值列允许空值（该日无数据跳过）；日期升序或乱序均可（解析后按日期合并）。

脚本模板和「AI 辅助」提示词内置这份契约。

## 3. 设置项

`StrataBoardSettings` 新增：

- `scriptFolderPath: string`，默认 `"金融卡片/脚本"`。路径设置 tab 新增一行 `addFolderPathSetting`（挂在「卡片路径」details 内，`settings.ts renderPathSettings()` L691）。
- `disabledScripts: string[]`（脚本文件名列表，默认 `[]`）。默认启用；禁用只置灰手动「立即运行」。

i18n：所有新 UI 字符串走 `t("中文")` 并在 `EN` map 补译文。

## 4. 脚本产物 → CSV 源自动注册

新模块 `src/modules/script-sources.ts`：

- `syncScriptSources(plugin)`：扫描 `scriptFolderPath/output/*.csv`，对每个文件：
  - 若 `customSources` 中已存在 `id === "script:<文件名slug>"` 的源 → 跳过（用户的改名/禁用状态不动）。
  - 否则读文件头几行，复用 `csv-source-modal.ts` 的 `deriveMapping()` 逻辑（提取为可复用函数）判定 OHLCV / 宽表模式，构造 `CustomSourceDef`：
    `{ id: "script:<slug>", name: <文件名>, enabled: true, format: "csv", filePath, jsonMap, symbols }`
  - 经 `upsertCustomSource` → `saveSettings()` 通道写入（`settings.ts` L680），`main.ts:1758` 的 `setCustomSources` 热更新自动生效。
- 触发时机：插件 onload 一次；脚本文件夹内 CSV 的 create 事件各一次。
- 注册后自动出现在所有入口（`enabledCustomSources()` 汇总，unified search / 编辑弹窗 / ManualSymbolModal 均消费它，无需额外接线）。设置-自定义数据源列表里与普通 CSV 源同款展示，可禁用/删除；删除后被 watcher 再次发现的处理：删除即不再自动重建（在 `disabledScripts` 旁记一个 `removedScriptSources: string[]`，或简单起见删除时不重建、重启用 sync 按钮兜底——取简单方案：sync 只补「从未见过」的文件，见过即跳过）。

## 5. 变更监听与自动刷新

现状（调研结论）：插件没有任何 vault watcher；卡片重绘只靠各自 header 的刷新按钮；`CsvQuoteClient` 每次全量重读文件且 merge 幂等，但增量缓存存在盲区——脚本**重写历史行**时 extent 已覆盖该区间，改动不会进缓存。

新增（`main.ts`）：

1. `this.registerEvent(this.app.vault.on("modify", ...))`（及 create/delete），只处理 `scriptFolderPath/output/*.csv`。
2. 命中后：
   a. 找到对应源（`filePath` 匹配）；
   b. 用 `sqlite-cache` 已有的 targeted-delete 方法清掉该源全部缓存 key（`assetType === "custom:<sourceId>"`）——一步解决历史重写盲区，下次读取全量重拉（本地文件，成本低）；
   c. 重渲染受影响的卡片。
3. 渲染器注册表：插件维护 `Set<ChartCardRenderer>`，各渲染器 `onload/onunload`（MarkdownRenderChild 生命周期已有）时注册/注销。CSV 变更时先刷新 spec 直接引用该 sourceId 的卡；叠加/计算卡经 `SeriesRef.sourceId` 匹配；`source:"card"` 间接引用不做追踪（简化：间接引用的卡由全量刷新兜底——对脚本 CSV 变更改为「清缓存 + 刷新所有图表卡」，本地重读便宜，符合最简单实现原则）。
4. 防抖：同一文件 2s 内多次 modify 合并为一次（脚本写文件可能分多次 IO）。

「立即运行」按钮跑完脚本后走同一条路径（watcher 会兜住，但手动运行成功后直接触发一次，不等 watcher）。

## 6. 脚本管理弹窗

新 UI `src/ui/script-manager-modal.ts`，入口：

- 工具栏「数据处理」菜单新增「脚本处理」；
- 命令面板新增命令 `open-script-manager`。

内容：

- 脚本列表：扫描 `scriptFolderPath/*.py`，每行显示文件名、启用 toggle（写 `disabledScripts`）、「立即运行」按钮；产物 CSV 存在与否的状态标记。
- 立即运行：`execFile` 经 login shell 跑 `python3 <script>`（login shell 解析 PATH 解决 GUI 环境 PATH 残缺、180s 超时、maxBuffer 截断、SIGTERM 取消）。stdout/stderr 显示在弹窗日志区；非零退出码给出可读错误（含依赖缺失的 stderr 原文）。
- 「立即运行」对禁用脚本置灰。
- 顶部：「打开脚本文件夹」按钮（reveal in Finder / 系统文件管理器）。

## 7. AI 脚本助手（可复制提示词）

插件不内置 AI 助手。脚本管理弹窗的「AI 辅助」是一个无状态 details：一键复制的提示词（`AI_SCRIPT_PROMPT`，含 CSV 产物契约与合规规则），用户连同自己的脚本或报错一起贴给自己的 AI（Codex / Claude Code 等）。需要 AI 直接操作插件数据能力时走 MCP server / CLI（`src/mcp/server.ts`、`src/cli/`）。

- 提示词要点：产物契约（output/ 子目录、与脚本同名、UTF-8、宽表或单序列 OHLCV）、合规规则（不高频、不批量、增量抓取优先、只写 output/ 目录、请求间隔 ≥1s）。

## 8. 合规与免责声明

- 免责声明 tab（`renderDisclaimerSettings`）新增一段：脚本由用户自行编写与运行，脚本的数据获取行为及其与数据源之间的授权关系由用户负责；插件仅读取脚本产出的本地 CSV。
- 「AI 辅助」提示词中的规则段是主要约束载体；脚本模板（管理弹窗「新建脚本」生成的骨架）自带限速与增量抓取封装示例。
- 文档（README）说明脚本功能的边界：不适合高频数据、不做批量下载工具。

## 9. 实现步骤

Phase 1 — 契约与手动闭环（最小端到端）：
1. 设置项 `scriptFolderPath` + `disabledScripts`（settings.ts + DEFAULT_SETTINGS + 路径设置行）。
2. `script-sources.ts`：sync 注册 + onload 调用。
3. 脚本管理弹窗：列表、启用开关、立即运行（execFile）、日志区；工具栏/命令入口。
4. 脚本模板（新建脚本骨架，含契约注释与限速示例）。

Phase 2 — 自动刷新：
5. vault watcher（modify/create/delete）+ 防抖。
6. CSV 变更 → 清该源缓存 key → 刷新所有图表卡（渲染器注册表）。
7. CSV create → sync 注册。

Phase 3 — AI 辅助：
8. 弹窗内「AI 辅助」details：可复制提示词（`AI_SCRIPT_PROMPT`，含契约与合规规则）+ 复制按钮。

Phase 4 — 收尾：
10. 免责声明段落、README、i18n 英文译文、AGENTS.md 更新。
11. 构建部署到作者 vault，明暗主题各过一遍。

## 10. 明确不做

- 插件内定时调度（cron/interval）。需要定时由用户用操作系统能力；外部 AI（MCP/CLI）可以帮用户生成 crontab / 任务计划命令（纯文本输出，不执行系统级安装）。
- Python 环境管理（不装依赖、不管 venv）；依赖缺失以 stderr 原文呈现。
- vault 外的脚本/产物路径。
- 脚本与插件之间的任何进程内接口（唯一契约是 CSV 文件）。
- 对 `source:"card"` 间接引用链的精确失效追踪（全量刷新兜底）。
